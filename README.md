# 机器人实证：公开证据研究工作台

面向会看财报、没有时间逐一核实概念的个人投资者。入口为公司搜索，连接产业链归属、原始证据、中外比较、事件传导和手动更新。初始证据核查日为2026-09-30。

- 手动更新支持：查询报告 → 读取原文 → 提取证据候选 → 复核采纳 → 保存本机版本 → 查看差异、导出或恢复。

## 本地运行

建议Node.js 22或更高版本。在本目录执行：

```bash
npm install
npm run build
npm start
```

打开 http://127.0.0.1:8765 。如端口占用，可在 `.env` 中设置 `PORT=8766`，或执行：

```bash
PORT=8766 npm start
```

完整更新需要Node服务；直接打开HTML或使用纯静态服务器只能浏览基线证据，不能运行更新接口。服务器只暴露白名单内的前端文件，不公开 `.env`、部署凭证或源代码配置。

## 核心设计

### 分类与证据

按“产业方向 → 功能层 → 产品节点”组织自定义分类，分类版本保存在数据中。核心环节包括整机、执行器、精密传动、电机控制、感知和软件。后两类尚未配置专门公司样本，不伪装成完整覆盖。

公司可归属多个节点，逐条保留具体产品、来源和定位。人形用途明确程度、业务阶段、来源内容与未知项分别展示。市场概念标签不构成业务归属证据。

六档为收入、订单/交付、客户验证、具体研发、仅表态和证据不足。资料不足时允许无法判断；不强行将所有公司塞进某个等级。“具备能力”不等于“实际交付”，行业收入不等于公司收入，机器人收入不等于人形收入。六档规则有测试覆盖；现有真实样本未强行凑齐所有档位。

### 中外比较与事件

整机对照：优必选与Tesla；精密传动对照：绿的谐波与Harmonic Drive Systems。按产品层级、披露进度、用途与财务口径列出可比与不可比部分，不计算缺乏依据的人形业务纯度或估值。

事件案例基于Tesla第二季度报告中的Optimus规模生产准备披露。事实、需求假设、供应关系证据缺口、交付确认和财务影响分别呈现。没有凭该消息认定任何中国样本为Optimus供应商。收入算术情景由用户输入参数，不能替代公司业绩预测。

### 手动更新与版本

A股接口实际检索巨潮年度及半年度报告（2025年至查询日），不覆盖全部临时公告、互动回复或研报。其他市场目前复核已登记来源，明确标注覆盖范围。

PDF提取后保留页码、短摘录与文件SHA-256。遇到源站拒绝、超时、扫描件/编码失败或无命中时，保留旧结果，不能推断无业务。为了降低源站负担，报告列表和解析结果缓存5分钟。

候选结果需用户查看原文后确认采纳。本机存储最多30个版本，支持导出和恢复基线。新增更弱证据或较旧报告不会自动降低已有阶段；只有人形用途明确、时间不早于现有依据、阶段更高的证据才允许复核后的升级。单个片段仍可能失去上下文，因此结果明确属于用户研究标注。比较表和公共基线不随个人标注自动重写。

当前历史存于localStorage，不是多用户服务器数据库；清理浏览器会删除记录。新增证据仍需产品用途复核，本轮未实现完整矛盾解决、降级审核和多人审批。

## AI角色与模型接入

开发阶段AI用于检索、提取、口径辨析、界面实现及验证。运行时提供可选的兼容Chat Completions接口，服务端配置以下三项：

```text
MODEL_ENDPOINT=https://your-provider.example/v1/chat/completions
MODEL_API_KEY=在服务器秘密配置中填写
MODEL_NAME=提供商支持的模型
```

也兼容经账号授权配置的EdgeOne模型网关变量。密钥不进入前端、仓库或导出记录。

模型只从原文候选中选择连续摘录；服务端核对页码及原文包含关系，拒绝凭空生成的证据。业务阶段使用保守规则，最终由用户复核。无凭证、模型超时、错误或摘录校验失败时，明确降级为规则提取。原文包含校验不能保证业务语义正确，因此仍保留未确认项和审核步骤。

## 数据使用

来源为巨潮资讯、港交所、SEC及公司官网的公开材料。保留原文链接和必要短摘录，不重新分发全部财报或付费研报。原始文件指纹记录下载版本；SEC条目未缓存完整文件，其哈希为null，未伪造缓存记录。

行业热门入口保留，但没有行情授权接口时显示缺失状态，不制造涨跌幅、成交额或排名。产业代表按产品研究需要选入，列明选入理由。

## 部署

EdgeOne配置在 `edgeone.json`，前端产物仅进入 `public/`；Node接口在 `cloud-functions/api/`。发布前需在用户账号下确认访问区域、长期域名和模型环境变量，并实测大陆网络访问、资源加载和API。域名可访问不等于大陆所有运营商均可访问。

```bash
npm run build
edgeone makers deploy --site china
```

当前临时发布未通过访问验收，勿直接作为最终提交URL。部署凭证位于忽略目录，不进入源码包。
